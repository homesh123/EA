📚 RAG: letting an LLM answer from your documents

EnglishHinglish

🏠 Real-life example

An open-book exam: you don't memorise the whole textbook. When a question comes, you find the right pages, read them, and write your answer from them, citing the chapter. RAG (Retrieval-Augmented Generation) makes an LLM take an open-book exam with your company's documents.

💡 In simple words

There are two phases. Indexing: split documents into chunks (a few paragraphs each), create an embedding for each chunk, and store them in a vector database. Answering: embed the user's question, retrieve the most relevant chunks, put them into the prompt ('Answer only from these sources…'), and let the LLM write the answer with citations. RAG keeps answers current and grounded in your data without retraining the model. Most RAG quality problems are retrieval problems, such as bad chunking or missing documents, so measure retrieval separately from the final answer.

🎬 See how it works

Indexing happens once: documents → chunks → embeddings → vector DB. For each question, retrieve the best chunks, add them to the prompt, and answer with the source.

🔑 Key terms

Chunking
Splitting documents into small, searchable pieces.
Retrieval
Finding the most relevant chunks for a question.
Grounding / citations
Answering only from the retrieved sources and showing which ones.

👀 See it in action

python
question = "How many casual leaves do new joiners get?"
chunks = vector_db.search(embed(question), top_k=4)          # retrieve
context = "\n\n".join(f"[{c.source}] {c.text}" for c in chunks)
prompt = f"Answer ONLY from the sources below. Cite them. If not found, say so.\n\n{context}\n\nQ: {question}"
answer = llm(prompt)   # → "New joiners get 8 casual leaves per year [HR-Policy-2026 §4.2]"

Retrieve → augment the prompt → generate. Plus an honest 'not found' rule.

✅ Quick check

Your RAG bot gives wrong answers. The right document exists, but it's never retrieved. What should you fix first?

  1. Increase temperature
  2. Switch to a bigger LLM
  3. Retrieval: chunking, embeddings or hybrid search
Show answer

C. Retrieval: chunking, embeddings or hybrid search: If the right text never reaches the prompt, no LLM can answer correctly. Fix retrieval first.
