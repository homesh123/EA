🕸️ Neural networks: layers jo seekhti hain

EnglishHinglish

🏠 Real-life example

Handwritten digit pehchaanne ke liye ek factory assembly line socho. Pehle workers simple strokes aur edges pakadte hain. Agle unhe jodkar curves aur loops banaate hain. Aakhri workers kehte hain 'upar loop plus neeche line: yeh 9 hai'. Workers ka har group ek layer hai, aur training har worker ko sikhaati hai ki kya dhoondhna hai.

💡 Aasaan shabdon mein

Neural network simple units (neurons) ki layers hai. Har neuron numbers leta hai, unhe seekhe hue weights se multiply karta hai, jodta hai, aur result ko ReLU jaisi activation function se guzaarta hai, jo non-linearity jodti hai. Bahut saari layers stack karne se ('deep' learning) network zyaada complex patterns seekh paata hai. Training forward chalti hai (prediction karo), loss naapti hai, phir backpropagation aur gradient descent se weights update karti hai, kai passes (epochs) tak. PyTorch sabse popular library hai. Convolutional networks (CNNs) images mein specialist hain.

🔑 Key terms

Weight
Seekha hua number jo decide karta hai ki input kitna matter karta hai.
Activation function
Chhota function (jaise ReLU) jo networks ko tedhe-medhe patterns seekhne deta hai.
Epoch
Training data ka ek poora chakkar.

👀 Example dekho

python
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(784, 128), nn.ReLU(),   # 28×28 image → 128 features
    nn.Linear(128, 64),  nn.ReLU(),
    nn.Linear(64, 10)                 # scores for digits 0–9
)

Handwritten digits ke liye ek chhota 3-layer network.

✅ Quick check

Neural network mein 'weights' kya represent karte hain?

  1. Dataset ka size
  2. Seekhe hue numbers jo decide karte hain ki har input kitna matter karta hai
  3. GPU ki memory
Jawaab dekho

B. Seekhe hue numbers jo decide karte hain ki har input kitna matter karta hai: Training weights ko adjust karti hai. Network jo 'jaanta' hai, woh yahi weights hain.

📌 Yaad rakho

Weighted sums aur activations ki layers, backprop se train hoti hain.
