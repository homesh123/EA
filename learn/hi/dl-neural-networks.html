🕸️ Neural networks: layers jo seekhti hain

EnglishHinglish

🏠 Asli zindagi ki misaal

Handwritten digit pehchaanne ke liye ek factory assembly line socho. Pehle workers simple strokes aur edges pakadte hain. Agle unhe jodkar curves aur loops banaate hain. Aakhri workers kehte hain 'upar loop plus neeche line: yeh 9 hai'. Workers ka har group ek layer hai, aur training har worker ko sikhaati hai ki kya dhoondhna hai.

💡 Aasaan shabdon mein

Neural network simple units (neurons) ki layers hai. Har neuron numbers leta hai, unhe seekhe hue weights se multiply karta hai, jodta hai, aur result ko ReLU jaisi activation function se guzaarta hai, jo non-linearity jodti hai. Bahut saari layers stack karne se ('deep' learning) network zyaada complex patterns seekh paata hai. Training forward chalti hai (prediction karo), loss naapti hai, phir backpropagation aur gradient descent se weights update karti hai, kai passes (epochs) tak. PyTorch sabse popular library hai. Convolutional networks (CNNs) images mein specialist hain.

🎬 Dekho kaise kaam karta hai

Signals left se right jaate hain: pixels → simple patterns (edges) → bade patterns (loops) → jawaab. Training har connection ka weight adjust karti hai.

🪜 Step by step

  1. Input layer: raw numbers (pixels, word embeddings, features).
  2. Hidden layers: har neuron apne inputs ka weighted sum nikaalta hai aur ReLU jaise activation se guzaarta hai, taaki network sirf seedhi line nahi, curves bhi seekh sake.
  3. Output layer: regression ke liye number, ya classes ke liye probabilities (softmax).
  4. Training: predict karne ke liye forward pass, error naapne ke liye loss, gradients ke liye backpropagation, weights update karne ke liye optimiser.
  5. Dropout, weight decay aur early stopping se regularise karo, aur jab ho sake pretrained models use karo.

🔑 Zaroori shabd

Weight
Seekha hua number jo decide karta hai ki input kitna matter karta hai.
Activation function
Chhota function (jaise ReLU) jo networks ko tedhe-medhe patterns seekhne deta hai.
Epoch
Training data ka ek poora chakkar.

👀 Example dekho

python
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(784, 128), nn.ReLU(),   # 28×28 image → 128 features
    nn.Linear(128, 64),  nn.ReLU(),
    nn.Linear(64, 10)                 # scores for digits 0–9
)

Handwritten digits ke liye ek chhota 3-layer network.

⚠️ Aam galtiyaan jinse bachna hai

  • Chhote dataset pe bada network shuru se train karna. Iske bajaye pretrained model fine tune karo.
  • Inputs normalise na karna. Inputs ke scale bahut alag hon to neural networks theek se train nahi hote.

✅ Jaldi se check karo

Neural network mein 'weights' kya represent karte hain?

  1. Dataset ka size
  2. GPU ki memory
  3. Seekhe hue numbers jo decide karte hain ki har input kitna matter karta hai
Jawaab dekho

C. Seekhe hue numbers jo decide karte hain ki har input kitna matter karta hai: Training weights ko adjust karti hai. Network jo 'jaanta' hai, woh yahi weights hain.

🙋 Seekhne wale yeh poochhte hain

Inhe 'deep' kyun kehte hain?

Kyunki inme bahut saari layers ek ke upar ek hoti hain. Har layer pichhli se zyaada abstract features banati hai: edges, shapes, phir objects.

PyTorch ya TensorFlow?

Aaj research aur zyaadatar naye projects mein PyTorch sabse common hai. Concepts dono mein kaam aate hain.
