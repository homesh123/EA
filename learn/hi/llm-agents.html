🤖 AI agents: plan, act, observe, repeat

EnglishHinglish

🏠 Real-life example

Goa trip plan karte waqt aap flight prices dekhte ho, phir beach ke paas hotels, phir notice karte ho ki hotel airport se door hai, to doosre airport ki flights dobara check karte ho, aur phir book karte ho. Aap plan karte ho, act karte ho, result dekhte ho aur adjust karte ho. AI agent bhi isi loop mein kaam karta hai, har step pe tools use karke, jab tak task poora na ho.

💡 Aasaan shabdon mein

Agent loop mein chalta hua LLM hai: woh agla action decide karta hai, tool call karta hai, result padhta hai, aur tab tak repeat karta hai jab tak final jawaab na de sake ya limit na aa jaaye. Agents ko memory (ab tak kya hua), saaf tools, aur rukne ke rules chahiye, jaise maximum steps aur budget. LangGraph ya agent SDKs jaise frameworks loop aur state sambhaalte hain. Agents naye tareekon se fail hote hain: hamesha loop karte rehte hain, galat tool chun lete hain, ya kharab data pe action le lete hain. Fixed workflow se shuru karo, autonomy sirf wahan jodo jahan saaf faayda ho, aur high-impact steps pe insaan ki approval rakho.

🔑 Key terms

Agent loop
Socho → act (tool) → dekho → repeat.
State / memory
Task mein agent ne ab tak kya kiya aur kya seekha.
Guardrails
Steps, cost aur actions pe limits jo agent ko safe rakhti hain.

👀 Example dekho

text
Goal: "Find 3 well-rated cafés near Koramangala open after 10 pm"
Step 1 think → search_places("cafés Koramangala")
Step 2 observe → 12 results
Step 3 think → get_hours() for each, filter rating ≥ 4.2
Step 4 observe → 3 match
Step 5 → final answer with names, ratings, closing times ✅  (max_steps = 8)

Har step pichhle result ko use karta hai. Step limit endless loops ko rokti hai.

✅ Quick check

Agent same search tool 50 baar call karta ja raha hai. Isse kya rokna chahiye tha?

  1. Bada model
  2. Max-steps limit aur loop detection jaise guardrails
  3. Zyaada temperature
Jawaab dekho

B. Max-steps limit aur loop detection jaise guardrails: Agents ko saaf rukne ke rules chahiye. Sirf model ke bharose mat raho.

📌 Yaad rakho

Agent ka formula: LLM + tools + loop + memory + guardrails. Inmein se ek bhi kam, to agent bharosemand nahi.
