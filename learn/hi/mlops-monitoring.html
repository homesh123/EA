📡 Models ki monitoring: drift aur chupke se hone wale failures

EnglishHinglish

🏠 Real-life example

Diwali se pehle train hua demand-forecasting model tyohaar ke season mein achanak bilkul alag shopping patterns dekhta hai. Kuch 'crash' nahi hua, lekin uski predictions ab galat hain. Jaise gaadi ki alignment dheere-dheere bigadti hai, waise hi duniya badalne pe models drift hote hain, aur pata tabhi chalta hai jab aap check karte rehte ho.

💡 Aasaan shabdon mein

Software errors shor machaate hain. Model errors aksar chupchaap hote hain. Data drift matlab inputs badal gaye: naye tarah ke users, naye products, upstream ka koi field badal gaya. Concept drift matlab rishta badal gaya: jo pehle fraud ka signal tha, ab nahi hai. Input distributions, prediction distributions, data quality aur, labels aane pe, asli accuracy monitor karo. LLM apps ke liye har request trace karo (prompt, retrieve hue docs, output, cost, latency) aur user feedback track karo. Alerts aur retraining ya rollback ka plan zaroorat se pehle bana ke rakho.

🎬 Dekho kaise kaam karta hai

Kuch crash nahi hua, lekin tyohaar ke season mein inputs drift ho gaye. Monitoring alert threshold paar hone pe line pakad leti hai, isse pehle ki accuracy chupchaap gir jaaye.

🔑 Key terms

Data drift
Input data training data se alag dikhne lagta hai.
Concept drift
Model ne jo real-world rishta seekha tha, woh badal gaya.
Tracing
Debugging ke liye har request ke steps, inputs aur outputs record karna.

👀 Example dekho

text
Weekly monitor — fraud model v12
  avg transaction amount   ₹1,240 → ₹2,980   ⚠️ data drift (festival season)
  % flagged as fraud       1.1%  → 4.6%     ⚠️ prediction shift
  confirmed-fraud recall   0.81  → 0.62     🚨 alert → retrain with recent data

Inputs, outputs aur, jab ho sake, asli nateeje dekhte raho.

✅ Quick check

Bina code change ke mahino mein model accuracy dheere-dheere gir rahi hai. Sabse likely wajah?

  1. Bahut zyaada tests
  2. Syntax error
  3. Drift: real-world data ya rishte badal gaye
Jawaab dekho

C. Drift: real-world data ya rishte badal gaye: Duniya badalti hai to frozen model purana pad jaata hai. Yahi drift hai.

📌 Yaad rakho

Models chupchaap kharab hote hain. Inputs, outputs aur nateeje alerts ke saath monitor karo.
