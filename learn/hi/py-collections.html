🧺 Lists aur dictionaries: bahut saari values store karna

EnglishHinglish

🏠 Real-life example

Shopping list ordered hoti hai: pehle doodh, phir bread, phir ande. Yeh Python ki list hai. Phone ki contact book naam ko number se jodti hai: 'Amma → 98xxxx'. Aap position se nahi, naam se dhoondhte ho. Yeh dictionary hai.

💡 Aasaan shabdon mein

Real data groups mein aata hai, isliye Python mein collections hain. List [ ] items ko order mein rakhti hai, aur aap unhe position se access karte ho, jo 0 se shuru hoti hai. Dictionary { } key → value pairs store karti hai, aur aap key se value dhoondhte ho, jo bahut fast hota hai. Tuple ( ) list jaisa hai lekin badla nahi ja sakta, aur set sirf unique items rakhta hai. AI kaam mein aap jo data dekhoge, jaise APIs ka JSON, woh zyaadatar dictionaries ki list hota hai.

🔑 Key terms

List
Ordered collection: ['milk', 'bread'].
Dictionary
Key → value pairs: {'name': 'Asha', 'city': 'Pune'}.
Index
List mein item ki position. Pehla item index 0 pe hota hai.

👀 Example dekho

python
cart = ["milk", "bread", "eggs"]
print(cart[0])            # milk
cart.append("tea")

prices = {"milk": 30, "bread": 45, "eggs": 72, "tea": 120}
total = sum(prices[item] for item in cart)
print(total)              # 267

Cart ke items ke liye list, aur har item ka price dhoondhne ke liye dictionary.

✅ Quick check

Aapko roll number se student ke marks dhoondhne hain. Sabse best kya hai?

  1. List
  2. Ek string
  3. Dictionary
Jawaab dekho

C. Dictionary: Dictionary key (roll number) ko seedha value (marks) se map karti hai, position mein dhoondhna nahi padta.

📌 Yaad rakho

List = items ki ordered line. Dictionary = naam (key) se dhoondho.
