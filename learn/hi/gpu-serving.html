⚡ LLMs ko efficiently serve karna: GPUs, batching aur cost

EnglishHinglish

🏠 Real-life example

Ek baar mein ek passenger le jaane wala auto slow aur per person mehenga padta hai. Bus thode second rukkar bharti hai aur utne hi fuel mein kahin zyaada log le jaati hai. LLM servers isi wajah se ek GPU pe bahut saari user requests ko 'batch' karte hain: kahin behtar throughput, aur har request ki cost kam.

💡 Aasaan shabdon mein

Open models (Llama, Qwen, Mistral) khud host karne ke liye GPUs chahiye, aur GPUs mehenge hain. vLLM ya TGI jaise inference servers continuous batching (chalti requests ke beech nayi requests jodna) aur conversation cache ke liye efficient memory se GPU ka poora use karte hain. Key metrics: time to first token (jawaab kitni jaldi shuru hota hai), tokens per second, p95 latency aur har 1,000 requests ki cost. Quantisation models ko chhota karke saste GPUs mein fit karta hai, repeat prompts ki caching paise bachaati hai, aur saamne laga LLM gateway traffic route karta hai, budgets lagaata hai aur providers ke beech fallback karta hai.

🔑 Key terms

Batching
GPU ka poora use karne ke liye bahut saari requests ek saath process karna.
Time to first token
Jawaab ke pehle words kitni jaldi dikhte hain.
p95 latency
95% requests isse fast hain. Slow wali requests isse pakdi jaati hain.

👀 Example dekho

bash
pip install vllm
vllm serve Qwen/Qwen2.5-7B-Instruct --max-model-len 8192
# → OpenAI-compatible API on :8000 with continuous batching built in

# Track: time-to-first-token, tokens/sec, p95 latency, GPU utilisation, ₹ per 1k requests

Ek command se batched, production-style LLM server mil jaata hai.

✅ Quick check

Users wait kar rahe hain aur GPU sirf 20% use ho raha hai. Sabse zyaada kya madad karega?

  1. Bada model
  2. Continuous batching wala inference server
  3. Aur GPUs khareedo
Jawaab dekho

B. Continuous batching wala inference server: Batching same GPU pe zyaada requests daalta hai, jisse utilisation aur throughput badhte hain.

📌 Yaad rakho

Requests batch karo, latency aur cost naapo, aur jahan ho sake quantise aur cache karo.
