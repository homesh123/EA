🔐 Enterprise AI: integration, security aur compliance

EnglishHinglish

🏠 Real-life example

Hospital visiting specialist ko andar aane deta hai, lekin aise visitor badge ke saath jo sirf kuch darwaaze kholta hai, har entry log hoti hai, aur koi patient file building se bahar nahi jaati. Company mein AI laana bhi aise hi kaam karta hai: woh legacy systems se controlled darwaazon ke through judta hai, har user ko sirf wahi dikhata hai jo use dekhne ki permission hai, aur audit trail chhodta hai.

💡 Aasaan shabdon mein

Enterprise AI projects model se nahi, integration aur bharose se safal ya fail hote hain. Existing systems (CRMs, ERPs, document stores) se unki APIs ke through, sahi authentication (SSO, OAuth, service accounts) ke saath judo. RAG ko permission-aware banao: sirf woh documents retrieve karo jo poochne wale user ko dekhne ki permission hai. Personal data (PII) ko model tak pahunchne se pehle mask karke bachao, aur pata rakho ki data kahan store aur process hota hai (data residency). Audits ke liye har prompt, tool call aur jawaab log karo. Client ki security team ke saath shuru mein hi requirements ko GDPR, India ke DPDP Act, HIPAA ya SOC 2 jaise frameworks se map karo.

🔑 Key terms

PII
Personally identifiable information: naam, phone number, Aadhaar, address.
Permission-aware retrieval
Search jo har user ke access rights ka dhyaan rakhe.
Audit log
Kisne kab kya kiya, iska aisa record jise badla na ja sake.

👀 Example dekho

text
HR assistant asks: "What is Priya's salary?"
  1. Identify the user via SSO → role = 'team lead'
  2. Retrieval filter: only documents this role can read → salary files excluded
  3. Answer: "I can't share individual salary details."
  4. Audit log: user, question, documents checked, answer, timestamp

Security system lagaata hai. Model ke mana karne ki ummeed pe nahi chhodi jaati.

✅ Quick check

Do employees same RAG bot se confidential plans ke baare mein poochte hain. Kya alag hona chahiye?

  1. Kuch nahi, dono ko same jawaab
  2. Har insaan ki permissions ke hisaab se retrieve hone wale documents
  3. Sirf font
Jawaab dekho

B. Har insaan ki permissions ke hisaab se retrieve hone wale documents: Permission-aware retrieval yeh pakka karta hai ki har user sirf wahi content dekhe jiski use permission hai.

📌 Yaad rakho

Access enforce karo, PII mask karo, sab log karo, aur security team ko jaldi shaamil karo.
