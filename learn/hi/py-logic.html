🔁 Python logic: if/else, loops aur functions

EnglishHinglish

🏠 Real-life example

Traffic signal decision leta hai: agar red hai to ruko, warna agar green hai to chalo. Yeh hai if/else. Washing machine ek hi rinse cycle kai baar repeat karti hai. Yeh hai loop. Aur mummy ki chai ki recipe ek baar likhi hui hai aur roz subah reuse hoti hai. Yeh hai function: steps ko ek baar pack karo aur jab chahiye tab call karo.

💡 Aasaan shabdon mein

Programs ko decisions lene padte hain, kaam repeat karna padta hai aur organised rehna padta hai. 'if / elif / else' condition ke hisaab se alag code chalata hai. 'for' loop collection ke har item ke liye code repeat karta hai, aur 'while' loop tab tak repeat karta hai jab tak condition false na ho jaaye. Function ('def' se banta hai) steps ko ek naam ke neeche bundle karta hai, inputs (parameters) leta hai aur 'return' se output deta hai. Achhe functions ek hi clear kaam karte hain, isliye code ko test aur reuse karna aasaan hota hai.

🔑 Key terms

Condition
Aisa sawaal jiska jawaab True/False ho, jaise price > 100.
Loop
Code jo har item ke liye, ya condition badalne tak, repeat hota hai.
Function
Naam wala, reusable code block jismein inputs aur ek output hota hai.

👀 Example dekho

python
def bill(amount):
    if amount >= 500:
        return amount * 0.9   # 10% off on big orders
    return amount

orders = [120, 650, 300]
for o in orders:
    print(o, "→", bill(o))
# 120 → 120, 650 → 585.0, 300 → 300

Kirana store ka discount rule ek baar likha aur har order ke liye use kiya.

✅ Quick check

Aapko 1,000 orders pe same discount rule lagaana hai. Kya use karoge?

  1. Code 1,000 baar copy-paste karna
  2. Loop ke andar function
  3. Sirf ek if statement
Jawaab dekho

B. Loop ke andar function: Rule ko ek baar function mein likho, phir orders pe loop chala kar har ek ke liye call karo.

📌 Yaad rakho

if = decide karo, loop = repeat karo, function = reuse karo.
