📐 Vectors aur matrices: AI ki bhasha

EnglishHinglish

🏠 Asli zindagi ki misaal

Ek phone ko numbers se describe karo: [price, battery, camera MP, weight] = [20000, 5000, 50, 190]. Yeh list ek vector hai, aur milte-julte vectors wale do phones milte-julte phones hain. 100 phones ki spreadsheet, jismein har row ek vector hai, ek matrix hai. AI models zyaadatar bahut saari fast vector aur matrix maths hi hain.

💡 Aasaan shabdon mein

Vector numbers ki ordered list hai jo kisi cheez ko represent karti hai: data ki row, image, ya kisi word ka matlab. Matrix numbers ka grid hai, yaani bahut saare vectors ek ke upar ek. Key operations: dot product batata hai ki do vectors kitne ek hi direction mein hain (similarity search ka base), aur matrix multiplication vectors ko transform karta hai (har neural-network layer yahi karti hai). Eigenvectors data mein variation ki main directions batate hain. Inhe haath se calculate nahi karna padta; NumPy aur PyTorch kar dete hain. Lekin inka matlab samajhne se papers aur models padhne laayak ho jaate hain.

🪜 Step by step

  1. Vector numbers ki list hai: ek ghar jaise [3 bedrooms, 1200 sq ft, centre se 8 km].
  2. Matrix numbers ki table hai: bahut saare ghar, har ek ki ek row.
  3. Dot product matching numbers ko multiply karke jodta hai. Model ka prediction aksar features aur weights ka dot product hota hai.
  4. Matrix multiplication ek saath bahut saare dot products karta hai. GPUs isi mein tez hain, isliye AI unpe chalta hai.
  5. Cosine similarity do vectors ki direction compare karti hai. Milte julte matlab ki direction milti julti hoti hai, isi se semantic search chalta hai.

🔑 Zaroori shabd

Vector
Numbers ki ordered list jo ek cheez ko describe kare.
Dot product
Matching numbers multiply karke jodo. Zyaada value matlab zyaada aligned.
Matrix multiplication
Ek saath bahut saare vectors transform karna. Neural layer ka core kaam.

👀 Example dekho

python
import numpy as np
you   = np.array([5, 1, 4])   # likes: cricket, cooking, movies (0–5)
riya  = np.array([4, 0, 5])
vikas = np.array([0, 5, 1])
print(you @ riya)    # 40 → very similar tastes
print(you @ vikas)   # 9  → quite different

Dot product ek simple 'pasand ki similarity' score ki tarah. Recommenders yahi idea use karte hain.

⚠️ Aam galtiyaan jinse bachna hai

  • Shapes mein gadbad. (3×2) matrix sirf 2 rows wali cheez se multiply ho sakti hai. Debug karte waqt shapes print karo.
  • Bahut alag scale wale vectors (rupees vs counts) bina scaling compare karna. Ek feature distance pe haavi ho jaata hai.

✅ Jaldi se check karo

Do vectors ka dot product bada positive hai. Woh shayad…

  1. Similar hain / same direction mein hain
  2. Khaali hain
  3. Bilkul alag hain
Jawaab dekho

A. Similar hain / same direction mein hain: Bada positive dot product matlab vectors milti-julti direction mein point karte hain, yaani similar hain.
