🌳 Git aur GitHub: apna kaam save aur share karna

EnglishHinglish

🏠 Real-life example

Important document likhte waqt log 'report_final', 'report_final_v2', 'report_FINAL_pakka' save karte hain. Git yahi kaam theek se karta hai. Har 'commit' ek label wala save point hai jahan aap wapas ja sakte ho. GitHub code ke liye Google Drive jaisa hai: aapka project online rakhta hai, aur recruiters ko dikhata hai ki aapne kya banaya hai.

💡 Aasaan shabdon mein

Git ek version-control tool hai. Yeh files ke har change ko track karta hai, taaki aap history dekh sako, galtiyaan undo kar sako, aur doosron ke saath kaam kar sako bina ek-doosre ka kaam overwrite kiye. Basic cycle hai: files edit karo → 'git add' (changes chuno) → 'git commit' (message ke saath save) → 'git push' (GitHub pe upload). Branches se aap main version ko tode bina kuch naya try kar sakte ho. AI hiring manager aksar sabse pehle aapki public GitHub profile hi dekhta hai.

🎬 Dekho kaise kaam karta hai

Har dot ek commit (save point) hai. Branch se aap safely kuch try karte ho, phir merge karke GitHub pe push karte ho.

🔑 Key terms

Commit
Project ka saved snapshot, ek chhote message ke saath.
Repository (repo)
Git se track hone wala project folder.
Branch
Kaam ki alag line, taaki aap safely experiment kar sako.

👀 Example dekho

bash
git init                         # start tracking this folder
git add analysis.py
git commit -m "Add sales analysis"
git push origin main             # upload to GitHub

Yeh chaar commands aap roz use karoge.

✅ Quick check

Kaunsi command message ke saath save point banati hai?

  1. git init
  2. git commit
  3. git push
Jawaab dekho

B. git commit: commit snapshot ko local save karta hai. Phir push aapke commits ko GitHub pe upload karta hai.

📌 Yaad rakho

add → commit → push. Chhote aur baar-baar commits karo, saaf messages ke saath.
