What is System prompt?System prompt kya hai?

Also called: System message

System prompt: Instructions given to an LLM before the conversation that set its role, rules and format.Baatcheet se pehle LLM ko diye instructions jo uska role, rules aur format tay karte hain.

🧸 Think of it likeAise samjho

Like the briefing a manager gives a new shop assistant on day one: who you are, how to talk to customers, and what never to do.Jaise manager pehle din naye shop assistant ko briefing deta hai: tum kaun ho, customers se kaise baat karni hai, aur kya kabhi nahi karna.

📘 ExplainedVistaar se

The system prompt defines who the assistant is, what it may and may not do, the tone and the output format. It applies to every user message. It's not a security boundary: sensitive rules must also be enforced in code.System prompt tay karta hai assistant kaun hai, kya kar sakta aur kya nahi, tone aur output format. Yeh har user message pe laagu hota hai. Yeh security boundary nahi hai: sensitive rules code mein bhi lagne chahiye.

💡 Real exampleAsli example

'You are a polite support assistant for Acme Bank. Answer only from the provided policy.'System prompt: 'Aap Acme Bank ke vinamra support assistant ho. Sirf di gayi policy se jawaab do.'

It applies to every user message. It's not a security boundary: sensitive rules must also be enforced in code.
