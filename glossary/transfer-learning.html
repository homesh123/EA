What is Transfer learning?Transfer learning kya hai?

Transfer learning: Starting from a model trained on one task and adapting it to another, so you need far less data.Ek task pe trained model se shuru karke use doosre task ke liye adapt karna, taaki kaafi kam data chahiye.

🧸 Think of it likeAise samjho

Like a person who can ride a bicycle learning a scooter quickly: the balance is already learned.Jaise cycle chalaana jaanne wala scooter jaldi seekh leta hai: balance pehle se aata hai.

📘 ExplainedVistaar se

A model pretrained on millions of images or huge amounts of text already knows general patterns. Fine tuning it (or just its last layers) on a small dataset for your task works far better than training from scratch. It's the default approach in modern deep learning.Laakhon images ya bahut saare text pe pretrained model pehle se general patterns jaanta hai. Ise (ya sirf aakhri layers ko) apne task ke chhote dataset pe fine tune karna shuru se train karne se kahin behtar chalta hai. Aaj ki deep learning mein yahi default tarika hai.

💡 Real exampleAsli example

Adapting an image model to spot defects using 500 factory photos.500 factory photos se defects pakadne ke liye image model ko adapt karna.

Questions people ask

What is Transfer learning?

Starting from a model trained on one task and adapting it to another, so you need far less data. A model pretrained on millions of images or huge amounts of text already knows general patterns. Fine tuning it (or just its last layers) on a small dataset for your task works far better than training from scratch. It's the default approach in modern deep learning.

How can I understand Transfer learning in simple words?

Like a person who can ride a bicycle learning a scooter quickly: the balance is already learned.

What is an example of Transfer learning?

Adapting an image model to spot defects using 500 factory photos.

Transfer learning ka matlab kya hai?

Ek task pe trained model se shuru karke use doosre task ke liye adapt karna, taaki kaafi kam data chahiye. Jaise cycle chalaana jaanne wala scooter jaldi seekh leta hai: balance pehle se aata hai.
