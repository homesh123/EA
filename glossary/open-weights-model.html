What is Open weights model?Open weights model kya hai?

Also called: Open source model, Llama, Mistral

Open weights model: A model whose trained weights are published so anyone can download, run and fine tune it.Aisa model jiske trained weights publish hain, taaki koi bhi download, chala aur fine tune kar sake.

🧸 Think of it likeAise samjho

Like a recipe that's been published: anyone can cook it in their own kitchen and adjust the spices.Chhapi hui recipe jaisa: koi bhi apni kitchen mein bana sakta hai aur masale badal sakta hai.

📘 ExplainedVistaar se

Open weights models can run on your own servers, which helps with data privacy, cost at high volume and customisation. You take on hosting, scaling and safety work yourself. Check the licence: some allow commercial use with conditions.Open weights models aapke apne servers pe chal sakte hain, jo data privacy, zyaada volume pe cost aur customisation mein madad karta hai. Hosting, scaling aur safety ka kaam aapko khud karna padta hai. Licence check karo: kuch commercial use shart ke saath allow karte hain.

💡 Real exampleAsli example

Running a Llama model inside a bank's own data centre so customer data never leaves.Bank ke apne data centre mein Llama model chalana taaki customer data bahar na jaaye.

🔗 Related termsJude hue shabd

  • Foundation modelA large model trained on broad data that can be adapted to many tasks.Bade aur vyapak data pe train hua bada model jise kai kaamon ke liye adapt kiya ja sakta hai.
  • Fine tuningFurther training a pretrained model on your own examples to specialise its behaviour.Pretrained model ko apne examples pe aage train karke uska behaviour specialise karna.
  • QuantisationStoring model weights with fewer bits so models use less memory and run faster.Model weights ko kam bits mein rakhna taaki model kam memory le aur tez chale.
