What is Normalisation?Normalisation kya hai?

Also called: Scaling, LayerNorm

Normalisation: Rescaling numbers to a standard range so models train stably.Numbers ko standard range mein laana taaki models stable tarike se train hon.

🧸 Think of it likeAise samjho

Like converting marks out of 50 and out of 100 to percentages before comparing them.50 mein se aur 100 mein se marks ko compare karne se pehle percentage mein badalna.

📘 ExplainedVistaar se

For classic ML, scale features (for example to mean 0 and standard deviation 1) so large valued features don't dominate; fit the scaler on training data only. Inside neural networks, layers like BatchNorm and LayerNorm keep activations stable; transformers use LayerNorm.Classic ML mein features scale karo (jaise mean 0 aur standard deviation 1) taaki badi values wale features haavi na hon; scaler sirf training data pe fit karo. Neural networks ke andar BatchNorm aur LayerNorm jaisi layers activations stable rakhti hain; transformers LayerNorm use karte hain.

💡 Real exampleAsli example

Scaling salary (₹ lakhs) and age (years) so both matter fairly in a distance based model.Salary (₹ lakh) aur umar (saal) ko scale karna taaki distance based model mein dono barabar matter karein.
