What is BM25?BM25 kya hai?

Also called: Lexical search

BM25: A classic search method that ranks documents by matching words, used with vector search in hybrid search.Shabdon ke match se documents rank karne ka classic search tarika, hybrid search mein vector search ke saath use hota hai.

🧸 Think of it likeAise samjho

Like the index at the back of a textbook: it finds pages that contain the exact word you look up.Textbook ke peeche wale index jaisa: woh pages dhoondhta hai jismein wahi exact shabd hai jo aap dhoondh rahe ho.

📘 ExplainedVistaar se

BM25 scores a document higher when it contains the query's words, especially rare words, and adjusts for document length. It's excellent for exact terms like product codes, names and error numbers, where embeddings are weak. Combining BM25 with vector search (hybrid search) usually improves RAG retrieval.BM25 document ko tab zyaada score deta hai jab usme query ke shabd, khaaskar rare shabd, hon, aur document ki lambai ke hisaab se adjust karta hai. Product codes, naam aur error numbers jaise exact terms ke liye badhiya hai, jahan embeddings kamzor hain. BM25 ko vector search ke saath milana (hybrid search) aksar RAG retrieval sudhaarta hai.

💡 Real exampleAsli example

Questions people ask

What is BM25?

A classic search method that ranks documents by matching words, used with vector search in hybrid search. BM25 scores a document higher when it contains the query's words, especially rare words, and adjusts for document length. It's excellent for exact terms like product codes, names and error numbers, where embeddings are weak. Combining BM25 with vector search (hybrid search) usually improves RAG retrieval.

How can I understand BM25 in simple words?

Like the index at the back of a textbook: it finds pages that contain the exact word you look up.
