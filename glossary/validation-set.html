What is Validation set?Validation set kya hai?

Also called: Dev set

Validation set: Data used while building a model to compare options and tune settings.Model banate waqt options compare karne aur settings tune karne ke liye data.

🧸 Think of it likeAise samjho

Like mock tests during the year: you use them to decide how to study, not to get your final marks.Saal bhar ke mock tests jaisa: inse tay karte ho kaise padhna hai, final marks ke liye nahi.

📘 ExplainedVistaar se

You train on the training set, compare models and hyperparameters on the validation set, and keep the test set for the final check. Cross validation rotates the validation part for a more reliable estimate.Training set pe train karo, validation set pe models aur hyperparameters compare karo, aur final check ke liye test set rakho. Cross validation zyaada reliable estimate ke liye validation hissa baari baari badalta hai.

💡 Real exampleAsli example

Choosing between tree depth 4 and 8 based on validation F1.Validation F1 ke hisaab se tree depth 4 aur 8 mein chunna.

🔗 Related termsJude hue shabd

  • Test setData kept aside until the very end to get an honest measure of how a model performs on new data.Data jo bilkul aakhir tak alag rakha jaata hai taaki pata chale model naye data pe sach mein kaisa karta hai.
  • Cross validationRotating which part of the data is used for validation to get a more reliable score.Validation ke liye data ka hissa baari baari badal kar zyaada bharosemand score paana.
  • HyperparameterA setting you choose before training, like learning rate or tree depth, rather than something the model learns.Training se pehle chuni setting, jaise learning rate ya tree depth, jo model khud nahi seekhta.

Questions people ask

What is Validation set?

Data used while building a model to compare options and tune settings. You train on the training set, compare models and hyperparameters on the validation set, and keep the test set for the final check. Cross validation rotates the validation part for a more reliable estimate.
