What is Tool calling?Tool calling kya hai?

Also called: Function calling, tool use

Tool calling: Letting an LLM request actions or data from your code, like looking up an order or sending an email.LLM ko aapke code se actions ya data maangne dena, jaise order dhoondhna ya email bhejna.

🧸 Think of it likeAise samjho

Like a receptionist who can't see the stock room but can call the store keeper and ask 'is item 4512 in stock?'Receptionist jaisa jo store room nahi dekh sakta par storekeeper ko phone karke pooch sakta hai 'item 4512 stock mein hai?'

📘 ExplainedVistaar se

You describe tools with names and JSON schemas; the model replies with a tool call and arguments; your code validates them, runs the tool and returns the result; the model continues. The model never runs code itself. Keep tools small and clear, check permissions and require confirmation for risky actions.Tools ko naam aur JSON schemas se describe karte ho; model tool call aur arguments ke saath jawaab deta hai; aapka code unhe validate karta, tool chalata aur result lautata hai; model aage badhta hai. Model khud kabhi code nahi chalata. Tools chhote aur saaf rakho, permissions check karo aur risky actions pe confirmation maango.

💡 Real exampleAsli example

The user asks 'where is order 4512?' and the model calls get_order_status(4512).User poochhta hai 'order 4512 kahan hai?' aur model get_order_status(4512) call karta hai.

🔗 Related termsJude hue shabd

  • AgentAn LLM that works in a loop: plans a step, uses a tool, looks at the result, and decides the next step until the goal is done.Ek LLM jo loop mein kaam karta hai: step plan karta hai, tool use karta hai, result dekhta hai, aur goal poora hone tak agla step tay karta hai.
  • MCPAn open standard for connecting AI apps to tools and data, like a universal plug.AI apps ko tools aur data se jodne ka open standard, ek universal plug jaisa.
  • Structured outputMaking an LLM return data in a fixed format, like JSON with defined fields, so code can use it.LLM se tay format mein data lena, jaise defined fields wala JSON, taaki code use use kar sake.
