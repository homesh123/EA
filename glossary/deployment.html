AI dictionary · MLOps and deployment

What is Deployment?Deployment kya hai?

Also called: Serving, productionising

Deployment: Making a model available for real use, usually as an API or a scheduled job.Model ko asli use ke liye available karna, aam taur pe API ya scheduled job ke roop mein.

🧸 Think of it likeAise samjho

Like moving a dish from your home kitchen to a restaurant menu: now real customers can order it any time.Jaise ek dish ko ghar ki kitchen se restaurant ke menu pe laana: ab asli customers kabhi bhi order kar sakte hain.

📘 ExplainedVistaar se

Deployment packages the model with its preprocessing (often in Docker), serves it behind an API or runs it in batches, and adds monitoring, scaling and rollback. Safe rollouts use shadow mode or canaries. Most of the real effort in AI projects happens here, after the notebook.Deployment model ko uske preprocessing ke saath pack karta hai (aksar Docker mein), API ke peeche serve karta ya batches mein chalata hai, aur monitoring, scaling aur rollback jodta hai. Safe rollouts shadow mode ya canaries use karte hain. AI projects ki zyaadatar asli mehnat notebook ke baad yahin hoti hai.

💡 Real exampleAsli example

Wrapping a fraud model in FastAPI, packaging it with Docker and running it on Kubernetes.Fraud model ko FastAPI mein wrap karna, Docker se pack karna aur Kubernetes pe chalana.
