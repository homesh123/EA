What is Idempotency?Idempotency kya hai?

Also called: Idempotent

Idempotency: A job is idempotent if running it twice gives the same result as running it once.Job idempotent hai agar use do baar chalaane pe wahi result mile jo ek baar chalaane pe.

🧸 Think of it likeAise samjho

Like pressing a lift button twice: the lift still comes once.Lift ka button do baar dabaane jaisa: lift phir bhi ek hi baar aati hai.

📘 ExplainedVistaar se

Pipelines are retried and backfilled all the time. Writing by overwriting a date partition or upserting on a unique key, instead of blindly appending, makes reruns safe and prevents double counting. In APIs, idempotency keys stop duplicate payments when a request is retried.Pipelines baar baar retry aur backfill hoti hain. Bina soche append ke bajaye date partition overwrite ya unique key pe upsert karke likhne se reruns safe hote hain aur double counting rukti hai. APIs mein idempotency keys request retry hone pe duplicate payments rokti hain.

💡 Real exampleAsli example

Rerunning yesterday's sales load replaces yesterday's rows instead of adding them again.Kal ka sales load dobara chalaane pe kal ki rows badal jaati hain, dobara judti nahi.

Questions people ask

What is Idempotency?

A job is idempotent if running it twice gives the same result as running it once. Pipelines are retried and backfilled all the time. Writing by overwriting a date partition or upserting on a unique key, instead of blindly appending, makes reruns safe and prevents double counting. In APIs, idempotency keys stop duplicate payments when a request is retried.

How can I understand Idempotency in simple words?

Like pressing a lift button twice: the lift still comes once.

What is an example of Idempotency?
