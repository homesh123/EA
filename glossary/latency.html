What is Latency?Latency kya hai?

Also called: Response time, p95

Latency: How long a request takes from asking to getting the answer.Request bhejne se jawaab milne tak kitna time lagta hai.

🧸 Think of it likeAise samjho

Like the time between ordering a chai and getting it in your hand.Chai order karne aur haath mein aane ke beech ka time.

📘 ExplainedVistaar se

Measure percentiles, not just averages: p95 latency is the time within which 95% of requests finish. For LLMs, track time to first token (how soon text appears) and tokens per second. Reduce latency with streaming, shorter prompts, caching, smaller models and batching.Sirf average nahi, percentiles naapo: p95 latency woh time hai jisme 95% requests poori hoti hain. LLMs ke liye time to first token (text kitni jaldi dikhta hai) aur tokens per second track karo. Streaming, chhote prompts, caching, chhote models aur batching se latency kam karo.

💡 Real exampleAsli example

p95 latency of 800 ms means 95 of 100 requests finish within 0.8 seconds.p95 latency 800 ms matlab 100 mein se 95 requests 0.8 second mein poori hoti hain.
