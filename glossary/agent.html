What is Agent?Agent kya hai?

Also called: Autonomous agent

Agent: An LLM that works in a loop: plans a step, uses a tool, looks at the result, and decides the next step until the goal is done.Ek LLM jo loop mein kaam karta hai: step plan karta hai, tool use karta hai, result dekhta hai, aur goal poora hone tak agla step tay karta hai.

🧸 Think of it likeAise samjho

Like a smart assistant you give a goal, not steps: 'book me a cheap train to Pune on Friday'. It searches, compares, checks your calendar and comes back to you before paying.Ek smart assistant jaisa jise aap goal dete ho, steps nahi: 'Friday ko Pune ki sasti train book karo'. Woh search karta hai, compare karta hai, calendar check karta hai aur pay karne se pehle aapse poochta hai.

📘 ExplainedVistaar se

An agent gets a goal and a set of tools (search, database lookup, sending an email). In each turn the model decides which tool to call; your code runs the tool and gives the result back. This suits open ended tasks where the steps aren't known in advance. Because each step costs time and money and can go wrong, agents need limits (max steps, budgets), human approval for risky actions, tracing and evaluation. If the steps are fixed, a simple workflow is better.Agent ko ek goal aur kuch tools milte hain (search, database lookup, email bhejna). Har turn mein model tay karta hai kaunsa tool call karna hai; aapka code tool chalata hai aur result wapas deta hai. Yeh un open ended kaamon ke liye accha hai jinke steps pehle se pata nahi. Har step mein time aur paisa lagta hai aur galti ho sakti hai, isliye agents ko limits (max steps, budget), risky actions pe human approval, tracing aur evaluation chahiye. Steps fixed hon to simple workflow behtar hai.

💡 Real exampleAsli example

A support agent looks up the order, checks the refund policy and drafts a reply for a human to approve.Support agent order dhoondhta hai, refund policy check karta hai aur insaan ke approval ke liye reply draft karta hai.

Questions people ask

What is Agent?

An LLM that works in a loop: plans a step, uses a tool, looks at the result, and decides the next step until the goal is done. An agent gets a goal and a set of tools (search, database lookup, sending an email). In each turn the model decides which tool to call; your code runs the tool and gives the result back. This suits open ended tasks where the steps aren't known in advance. Because each step costs time and money and can go wrong, agents need limits (max steps, budgets), human approval for risky actions, tracing and evaluation. If the steps are fixed, a simple workflow is better.

How can I understand Agent in simple words?

Like a smart assistant you give a goal, not steps: 'book me a cheap train to Pune on Friday'. It searches, compares, checks your calendar and comes back to you before paying.

What is an example of Agent?
