What is Context window?Context window kya hai?

Also called: Context length

Context window: The maximum amount of text (in tokens) an LLM can consider at once, including its answer.Ek baar mein LLM jitna text (tokens mein) dekh sakta hai uski seema, uske jawaab samet.

🧸 Think of it likeAise samjho

Like the size of a desk: everything the model can look at right now must fit on it. Older papers fall off the edge.Desk ke size jaisa: model abhi jo kuch dekh sakta hai woh sab us par aana chahiye. Purane kaagaz kinaare se gir jaate hain.

📘 ExplainedVistaar se

Everything the model sees, system prompt, documents, chat history, tool results and output, must fit in the context window. Bigger windows allow longer documents but cost more and are slower, and models can miss details in the middle of very long inputs. RAG and summarising history keep context focused.Model jo kuch dekhta hai, system prompt, documents, chat history, tool results aur output, sab context window mein fit hona chahiye. Badi windows lambe documents allow karti hain par mehngi aur slow hain, aur bahut lambe inputs ke beech ki details model miss kar sakta hai. RAG aur history ka summary context focused rakhte hain.

💡 Real exampleAsli example

A 200,000 token window holds roughly a 500 page book.200,000 token ki window lagbhag 500 page ki kitaab sambhaal leti hai.

  • RAGLetting an LLM answer from your documents: search for relevant passages first, then generate an answer from them with citations.LLM ko aapke documents se jawaab dene dena: pehle relevant hisse dhoondho, phir unhi se citations ke saath jawaab banao.
  • Lost in the middleLLMs tend to use information at the start and end of a long prompt better than information in the middle.LLMs lambe prompt ki shuru aur aakhir ki information ko beech wali se behtar use karte hain.
