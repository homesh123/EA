What is Model?Model kya hai?

Model: The learned function that turns inputs into predictions or generated output.Seekha hua function jo inputs ko predictions ya generated output mein badalta hai.

🧸 Think of it likeAise samjho

Like a recipe the computer worked out by itself from examples: put inputs in, get a prediction out.Ek recipe jaisa jo computer ne examples se khud banayi: inputs daalo, prediction niklo.

📘 ExplainedVistaar se

In ML, a model is an algorithm plus its learned parameters (weights), saved to a file and loaded to make predictions. 'Model' can mean a small logistic regression or a huge LLM. In production it travels with its preprocessing and a version number.ML mein model ek algorithm plus uske seekhe hue parameters (weights) hai, jo file mein save hota hai aur predictions ke liye load hota hai. 'Model' chhota logistic regression bhi ho sakta hai aur bahut bada LLM bhi. Production mein yeh apne preprocessing aur version number ke saath chalta hai.

💡 Real exampleAsli example

fraud_model_v3.pkl, a trained XGBoost model with its feature pipeline.fraud_model_v3.pkl, apni feature pipeline ke saath trained XGBoost model.

🔗 Related termsJude hue shabd

  • ParameterA number inside a model that is learned during training; LLMs have billions of them.Model ke andar ka number jo training mein seekha jaata hai; LLMs mein arabon hote hain.
  • TrainingThe process where a model learns its parameters from data.Woh process jisme model data se apne parameters seekhta hai.
  • InferenceUsing a trained model to make predictions on new data.Trained model se naye data pe predictions karna.
