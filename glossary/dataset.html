What is Dataset?Dataset kya hai?

Dataset: A collection of examples used to train, validate or test a model.Model train, validate ya test karne ke liye examples ka collection.

🧸 Think of it likeAise samjho

Like a big recipe book of past examples that the model studies from.Pichhle examples ki ek badi recipe book jaisa, jisse model padhta hai.

📘 ExplainedVistaar se

A dataset might be rows in a table, images with labels, or question and answer pairs. Its quality, coverage and size often matter more than the model choice. Split it into training, validation and test sets, document where it came from, and check for duplicates, bias and leakage.Dataset table ki rows, labels wali images, ya sawaal jawaab ke jode ho sakte hain. Iski quality, coverage aur size aksar model ke chunaav se zyaada matter karte hain. Ise training, validation aur test sets mein baanto, kahan se aaya document karo, aur duplicates, bias aur leakage check karo.

💡 Real exampleAsli example

50,000 past loan applications with whether each was repaid.50,000 purani loan applications, har ek chukaaya gaya ya nahi uske saath.

🔗 Related termsJude hue shabd

  • LabelThe correct answer for an example, which a supervised model learns to predict.Example ka sahi jawaab, jise supervised model predict karna seekhta hai.
  • Test setData kept aside until the very end to get an honest measure of how a model performs on new data.Data jo bilkul aakhir tak alag rakha jaata hai taaki pata chale model naye data pe sach mein kaisa karta hai.
  • AnnotationAdding the correct answers (labels) to data so a model can learn from it.Data mein sahi jawaab (labels) jodna taaki model usse seekh sake.

What is Dataset?

A collection of examples used to train, validate or test a model. A dataset might be rows in a table, images with labels, or question and answer pairs. Its quality, coverage and size often matter more than the model choice. Split it into training, validation and test sets, document where it came from, and check for duplicates, bias and leakage.
