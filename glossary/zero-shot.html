What is Zero shot?Zero shot kya hai?

Also called: Zero shot prompting

Zero shot: Asking a model to do a task with instructions only, without giving examples.Model se bina examples, sirf instructions dekar task karwana.

🧸 Think of it likeAise samjho

Like asking a new helper to 'make tea for five' without showing them how: they rely on what they already know.Naye helper ko bina dikhaye 'paanch logon ki chai bana do' kehna: woh pehle se jo jaanta hai uspe chalta hai.

📘 ExplainedVistaar se

Modern LLMs handle many tasks zero shot: 'Classify this ticket as billing, delivery or technical.' If results are inconsistent, add a few examples (few shot) or a clearer output format.Aaj ke LLMs kai kaam zero shot kar lete hain: 'Is ticket ko billing, delivery ya technical mein classify karo.' Results consistent na hon to kuch examples (few shot) ya saaf output format jodo.

💡 Real exampleAsli example

Asking for a summary of a meeting transcript with no sample summaries.Bina sample summaries ke meeting transcript ka summary maangna.

📖 Learn it step by stepStep by step seekho

  • Prompting: giving clear instructions to an LLMPrompting: LLM ko saaf instructions dena

🔗 Related termsJude hue shabd

  • Few shot promptingShowing an LLM a few examples of the task inside the prompt so it copies the pattern.Prompt ke andar task ke kuch examples dikhana taaki LLM pattern copy kare.
  • PromptThe text you give an LLM: instructions, context and the question.Woh text jo LLM ko dete ho: instructions, context aur sawaal.
