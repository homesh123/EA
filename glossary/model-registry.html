AI dictionary · MLOps and deployment

What is Model registry?Model registry kya hai?

Model registry: A catalogue of trained model versions with their metrics and stage (testing, production).Trained model versions ka catalogue, unke metrics aur stage (testing, production) ke saath.

🧸 Think of it likeAise samjho

Like a library catalogue for models: which version exists, how good it was, and which one is on the shelf right now.Models ke liye library catalogue jaisa: kaunsa version hai, kitna achha tha, aur abhi shelf pe kaunsa hai.

📘 ExplainedVistaar se

Each registered model links to the training run, data version and evaluation results. Promotion to production is explicit, so you always know what's live and can roll back in one step. MLflow and cloud ML platforms provide registries.Har registered model training run, data version aur evaluation results se juda hota hai. Production mein promotion saaf hota hai, isliye hamesha pata hota hai kya live hai aur ek kadam mein rollback ho sakta hai. MLflow aur cloud ML platforms registries dete hain.

💡 Real exampleAsli example

churn-model v12 in production, v13 in staging awaiting approval.churn-model v12 production mein, v13 staging mein approval ke intezaar mein.
