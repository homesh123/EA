What is Few shot prompting?Few shot prompting kya hai?

Also called: In context learning

Few shot prompting: Showing an LLM a few examples of the task inside the prompt so it copies the pattern.Prompt ke andar task ke kuch examples dikhana taaki LLM pattern copy kare.

🧸 Think of it likeAise samjho

Like showing a new helper three folded shirts before asking them to fold the rest.Naye helper ko teen tah ki hui shirts dikha kar baaki tah karne ko kehna.

📘 ExplainedVistaar se

Instead of training, you include 2 to 5 input and output examples, then the new input. The model picks up the format and style. It's a fast way to improve consistency for classification, extraction and tone. Zero shot means giving instructions with no examples.Training ke bajaye 2 se 5 input output examples daalo, phir naya input. Model format aur style pakad leta hai. Classification, extraction aur tone mein consistency badhaane ka tez tarika hai. Zero shot matlab bina examples sirf instructions.

💡 Real exampleAsli example

Showing three tickets with their categories, then asking for the category of a fourth.Teen tickets unki categories ke saath dikha kar chauthe ki category poochhna.

📖 Learn it step by stepStep by step seekho

  • Prompting: giving clear instructions to an LLMPrompting: LLM ko saaf instructions dena

🔗 Related termsJude hue shabd

  • Prompt engineeringDesigning and testing prompts so an LLM gives reliable, useful output.Prompts design aur test karna taaki LLM reliable, kaam ka output de.
  • Zero shotAsking a model to do a task with instructions only, without giving examples.Model se bina examples, sirf instructions dekar task karwana.
