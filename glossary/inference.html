What is Inference?Inference kya hai?

Also called: Prediction, serving

Inference: Using a trained model to make predictions on new data.Trained model se naye data pe predictions karna.

🧸 Think of it likeAise samjho

Training is studying; inference is sitting the exam: using what was learned to answer a new question.Training padhai hai; inference exam dena hai: jo seekha use naye sawaal ka jawaab dene mein use karna.

📘 ExplainedVistaar se

Training happens occasionally; inference happens every time a user needs a prediction or an LLM answer. Inference must be fast, reliable and affordable, so it involves APIs, autoscaling, batching, caching and monitoring. For most companies inference is the main ongoing AI cost.Training kabhi kabhi hoti hai; inference har baar hota hai jab user ko prediction ya LLM jawaab chahiye. Inference tez, reliable aur sasta hona chahiye, isliye isme APIs, autoscaling, batching, caching aur monitoring aate hain. Zyaadatar companies ke liye inference hi AI ka main chalta kharch hai.

💡 Real exampleAsli example

Each time you ask a chatbot a question, the model runs inference.Har baar chatbot se sawaal poochhne pe model inference chalata hai.
