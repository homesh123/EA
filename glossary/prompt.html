What is Prompt?Prompt kya hai?

Prompt: The text you give an LLM: instructions, context and the question.Woh text jo LLM ko dete ho: instructions, context aur sawaal.

🧸 Think of it likeAise samjho

Like the instructions you give a new helper: what to do, the background they need, and how you want it done.Naye helper ko diye instructions jaisa: kya karna hai, zaroori background, aur kaise chahiye.

📘 ExplainedVistaar se

A prompt usually has a system part (role, rules, format) and user messages, plus any retrieved documents or tool results. Clear goals, needed context, explicit constraints, examples and an output format produce much better results. Treat prompts like code: version and test them.Prompt mein aam taur pe system hissa (role, rules, format) aur user messages hote hain, saath mein retrieved documents ya tool results. Saaf goals, zaroori context, saaf constraints, examples aur output format se kahin behtar results milte hain. Prompts ko code ki tarah treat karo: version aur test karo.

💡 Real exampleAsli example

'Summarise this complaint in 2 lines and suggest a reply in a polite tone.''Is complaint ka 2 line mein summary do aur vinamra tone mein reply suggest karo.'

🔗 Related termsJude hue shabd

  • Prompt engineeringDesigning and testing prompts so an LLM gives reliable, useful output.Prompts design aur test karna taaki LLM reliable, kaam ka output de.
  • System promptInstructions given to an LLM before the conversation that set its role, rules and format.Baatcheet se pehle LLM ko diye instructions jo uska role, rules aur format tay karte hain.
  • Few shot promptingShowing an LLM a few examples of the task inside the prompt so it copies the pattern.Prompt ke andar task ke kuch examples dikhana taaki LLM pattern copy kare.
