What is Label?Label kya hai?

Also called: Target, ground truth

Label: The correct answer for an example, which a supervised model learns to predict.Example ka sahi jawaab, jise supervised model predict karna seekhta hai.

🧸 Think of it likeAise samjho

The answer written on the back of a flashcard.Flashcard ke peeche likha jawaab.

📘 ExplainedVistaar se

In a churn dataset the label is 'cancelled: yes or no'; in price prediction it's the price. Labels can be noisy or delayed (fraud labels arrive weeks later via chargebacks). Label quality limits model quality.Churn dataset mein label 'cancel kiya: haan ya nahi' hai; price prediction mein price. Labels mein noise ya deri ho sakti hai (fraud labels hafton baad chargebacks se aate hain). Label ki quality model ki quality ki seema tay karti hai.

💡 Real exampleAsli example

Each past email marked 'spam' or 'not spam'.Har purana email 'spam' ya 'not spam' mark kiya hua.

🔗 Related termsJude hue shabd

  • FeatureOne input the model uses to make a prediction, like age, income or number of logins.Ek input jo model prediction ke liye use karta hai, jaise umar, income ya logins ki ginti.
  • AnnotationAdding the correct answers (labels) to data so a model can learn from it.Data mein sahi jawaab (labels) jodna taaki model usse seekh sake.
  • Supervised learningLearning from examples that come with the correct answers (labels).Aise examples se seekhna jinke saath sahi jawaab (labels) hote hain.
