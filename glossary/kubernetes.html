What is Kubernetes?Kubernetes kya hai?

Also called: K8s

Kubernetes: A system that runs and manages many containers across many servers: starting, scaling and healing them.System jo bahut saare servers pe bahut saare containers chalata aur sambhaalta hai: start, scale aur theek karna.

🧸 Think of it likeAise samjho

Like a building manager for containers: decides which flat each one lives in, adds more when it gets busy and replaces any that break.Containers ke liye building manager jaisa: tay karta hai kaun kis flat mein rahe, bheed hone pe aur jodta hai aur toote hue badal deta hai.

📘 ExplainedVistaar se

You describe what you want (for example 4 replicas of the model API with 2 GB memory each) and Kubernetes keeps it that way: it restarts failed containers, spreads traffic through Services, rolls out new versions gradually and autoscales. It's widely used for model serving and GPU workloads, though managed services are simpler for small projects.Aap batate ho kya chahiye (jaise model API ki 4 replicas, har ek 2 GB memory ke saath) aur Kubernetes waisa hi banaye rakhta hai: fail hue containers restart karta, Services se traffic baantta, naye versions dheere rollout karta aur autoscale karta hai. Model serving aur GPU workloads ke liye kaafi use hota hai, par chhote projects ke liye managed services simple hain.

💡 Real exampleAsli example

A crashed model pod is replaced automatically within seconds.Crash hua model pod seconds mein apne aap badal diya jaata hai.

Questions people ask

What is Kubernetes?

A system that runs and manages many containers across many servers: starting, scaling and healing them. You describe what you want (for example 4 replicas of the model API with 2 GB memory each) and Kubernetes keeps it that way: it restarts failed containers, spreads traffic through Services, rolls out new versions gradually and autoscales. It's widely used for model serving and GPU workloads, though managed services are simpler for small projects.

How can I understand Kubernetes in simple words?

Like a building manager for containers: decides which flat each one lives in, adds more when it gets busy and replaces any that break.

What is an example of Kubernetes?

A crashed model pod is replaced automatically within seconds.

Kubernetes ka matlab kya hai?

System jo bahut saare servers pe bahut saare containers chalata aur sambhaalta hai: start, scale aur theek karna. Containers ke liye building manager jaisa: tay karta hai kaun kis flat mein rahe, bheed hone pe aur jodta hai aur toote hue badal deta hai.
