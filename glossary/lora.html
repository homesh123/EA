What is LoRA?LoRA kya hai?

Also called: Low rank adaptation, QLoRA

LoRA: A cheap fine tuning method that trains small add-on matrices instead of the whole model.Sasta fine tuning tarika jo poore model ke bajaye chhote add-on matrices train karta hai.

🧸 Think of it likeAise samjho

Like adding a small clip on lens to your phone camera instead of buying a whole new camera.Naya camera kharidne ki jagah phone camera pe ek chhota clip on lens lagaane jaisa.

📘 ExplainedVistaar se

The base weights are frozen; LoRA learns a small low rank update for some layers, often under 1% of parameters. This cuts GPU memory and storage, and you can swap adapters per task. QLoRA keeps the base model in 4 bit precision so large models can be tuned on a single GPU.Base weights freeze rehte hain; LoRA kuch layers ke liye chhota low rank update seekhta hai, aksar 1% se kam parameters. Isse GPU memory aur storage kam lagti hai, aur har task ke liye adapters badal sakte ho. QLoRA base model ko 4 bit precision mein rakhta hai taaki bade models ek GPU pe tune ho sakein.

💡 Real exampleAsli example

A 30 MB LoRA adapter that makes a 7B model write in your company's report format.30 MB ka LoRA adapter jo 7B model ko company ke report format mein likhwata hai.

  • QuantisationStoring model weights with fewer bits so models use less memory and run faster.Model weights ko kam bits mein rakhna taaki model kam memory le aur tez chale.

Questions people ask

What is LoRA?

A cheap fine tuning method that trains small add-on matrices instead of the whole model. The base weights are frozen; LoRA learns a small low rank update for some layers, often under 1% of parameters. This cuts GPU memory and storage, and you can swap adapters per task. QLoRA keeps the base model in 4 bit precision so large models can be tuned on a single GPU.

How can I understand LoRA in simple words?

Like adding a small clip on lens to your phone camera instead of buying a whole new camera.

What is an example of LoRA?

A 30 MB LoRA adapter that makes a 7B model write in your company's report format.
