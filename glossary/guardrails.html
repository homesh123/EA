AI dictionary · Evaluation and safety

What is Guardrails?Guardrails kya hai?

Guardrails: Rules and checks around an AI system that block unsafe, wrong or costly behaviour.AI system ke around rules aur checks jo unsafe, galat ya mehenge behaviour ko rokte hain.

🧸 Think of it likeAise samjho

Like the railings on a mountain road: you can still drive freely, but they stop you going over the edge.Pahaadi sadak ki railing jaisa: aap aaraam se chala sakte ho, par woh kinaare se girne nahi deti.

📘 ExplainedVistaar se

Guardrails include input filters (prompt injection, abuse), output checks (personal data, policy violations, valid format), tool limits (permissions, max refund amount), agent limits (max steps, budgets) and human approval for risky actions. Important rules should be enforced in code, not only in the prompt.Guardrails mein input filters (prompt injection, abuse), output checks (personal data, policy ka ullanghan, valid format), tool limits (permissions, maximum refund amount), agent limits (max steps, budgets) aur risky actions pe human approval aate hain. Zaroori rules code mein lagne chahiye, sirf prompt mein nahi.

💡 Real exampleAsli example

A refund agent can't issue more than ₹2,000 without a person approving.Refund agent bina insaan ke approval ₹2,000 se zyaada nahi de sakta.
