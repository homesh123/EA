LLM / Agent Engineer roadmap: 6 steps

Follow the steps in order. Times assume about 10 study hours a week. Take the free questionnaire to get a personalised version that skips what you already know and fits your weekly hours.

  1. Step 1: LLM APIs, Prompting & Tool Use 1-2 weeks

    Call LLM APIs, write system prompts, get structured output and let the model call your functions.

    Why it matters: Tool use is the foundation of every agent.

    Learn from: Anthropic tool use docs (free), OpenAI function calling docs (free)

    Topics: System prompts, Structured output, Tool / function calling, Token & cost management

    Must-know: An LLM that calls a real API

  2. Step 2: Python for AI Engineering 2 weeks

    Async Python, typing, Pydantic and FastAPI — the stack most agent frameworks use.

    Why it matters: Agent frameworks are Python-first; production agents need solid code.

    Learn from: FastAPI docs (free), Pydantic docs (free)

    Topics: async / await, Pydantic models, FastAPI

    Must-know: Validate model output with Pydantic

  3. Step 3: Agent Frameworks & MCP 3-4 weeks

    Build agents with LangGraph or an agent SDK, connect tools via the Model Context Protocol (MCP), manage memory and state.

    Why it matters: These are the tools teams use to build agents today.

    Learn from: LangGraph docs (free), Claude Agent SDK docs (free), modelcontextprotocol.io (free)

    Topics: Agent loops, State & memory, MCP servers, Multi-agent patterns, Human-in-the-loop

    Must-know: Write your own MCP server

  4. Step 4: Build an Agent That Does Real Work 4 weeks

    An agent that completes a multi-step task end-to-end: research and report, triage tickets, or automate a business workflow.

    Why it matters: A working agent on a real task is the strongest signal for this role.

    Learn from: GitHub, framework examples

    Topics: Planning, Error recovery, Retries & timeouts, Approval steps

    Must-know: Demo video + trace logs

    Project ideas
    Support ticket triage agent: Reads tickets, looks up docs and order data via tools, drafts replies for approval
    Research & report agent: Searches the web, reads sources and writes a cited report

  5. Step 5: Evaluation, Observability & Safety 2-3 weeks

    Task success rates, trace-based debugging, guardrails, prompt-injection defence and cost control.

    Why it matters: Reliability is the #1 blocker for agents in production — engineers who solve it are in demand.

    Learn from: Langfuse / LangSmith docs (free), OWASP Top 10 for LLM apps (free)

    Topics: Eval suites, Tracing, Prompt injection, Cost budgets

    Must-know: Eval suite in CI

  6. Step 6: Target Agent Engineering Roles ongoing

    Apply for AI Agent Engineer, LLM Engineer and AI Automation roles.

    Why it matters: Show reliability, not only cleverness.

    Learn from: LinkedIn, Wellfound, AI company career pages

    Topics: Agent system design, Live coding with LLM APIs

    Must-know: Link demos and eval results
