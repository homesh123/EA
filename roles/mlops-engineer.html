MLOps / AI Platform Engineer roadmap: 6 steps

Follow the steps in order. Times assume about 10 study hours a week. Take the free questionnaire to get a personalised version that skips what you already know and fits your weekly hours.

  1. Step 1: ML Concepts for Infra Engineers 2-3 weeks

    How training, inference, model artifacts and evaluation work — enough to talk to ML teams.

    Why it matters: You can't build a platform for a workload you don't understand.

    Learn from: Google ML Crash Course (free), Made With ML (free)

    Topics: Training vs inference, Model artifacts, Batch vs real-time, GPU basics

    Must-know: Train and serve one small model yourself

  2. Step 2: Python for Automation 2 weeks

    Python scripting, packaging and testing at a level to work in ML codebases.

    Why it matters: ML platforms are built and glued together in Python.

    Learn from: Automate the Boring Stuff (free), pytest docs (free)

    Topics: Packaging, CLIs, Testing

    Must-know: Package a small tool

  3. Step 3: Model Packaging & Serving 3 weeks

    Serve classic models with FastAPI / BentoML and LLMs with vLLM or Triton; add an LLM gateway.

    Why it matters: Serving is the core of the job — latency, throughput and cost all live here.

    Learn from: vLLM docs (free), BentoML docs (free), MLflow docs (free)

    Topics: Model registries, vLLM, Batching & autoscaling, LLM gateways & caching

    Must-know: Serve an open model with vLLM

  4. Step 4: Kubernetes for AI Workloads 3-4 weeks

    GPU scheduling, Helm charts, autoscaling and KServe / Ray for model workloads.

    Why it matters: Most AI platforms run on Kubernetes — GPU-aware scheduling is a premium skill.

    Learn from: Kubernetes docs (free), KServe docs (free), Ray docs (free)

    Topics: GPU node pools, Helm, KServe, Ray

    Must-know: Deploy a model on K8s with autoscaling

  5. Step 5: ML Pipelines & Monitoring 3-4 weeks

    Automated training pipelines, model promotion, drift detection and LLM observability.

    Why it matters: Models silently degrade — platforms that detect it early save companies real money.

    Learn from: Kubeflow / Airflow docs (free), Evidently AI (free), Langfuse docs (free)

    Topics: CI/CD for models, Drift detection, LLM tracing, Alerting

    Must-know: End-to-end pipeline with monitoring

    Project ideas
    LLM serving platform: vLLM on Kubernetes with autoscaling, a gateway and Grafana dashboards
    ML CI/CD pipeline: GitHub Actions pipeline that trains, evaluates and promotes a model

  6. Step 6: Target AI Platform Roles ongoing

    Apply for MLOps, AI Platform and ML Infrastructure roles — or move into your company's AI platform team.

    Why it matters: Your on-call and reliability history is a strong selling point here.

    Learn from: LinkedIn, company career pages

    Topics: Infra system design, Cost optimisation stories

    Must-know: Show GPU / cost optimisation
