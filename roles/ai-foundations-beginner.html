What does a junior AI / ML engineer do?

You are early in your tech journey, so the fastest route is a solid foundation: Python, data, and core machine learning, proven with portfolio projects. This path leads to Junior ML Engineer, AI Engineer Trainee or Data Analyst (AI) roles.

Core skills

AI Foundations Path roadmap: 8 steps

Follow the steps in order. Times assume about 10 study hours a week. Take the free questionnaire to get a personalised version that skips what you already know and fits your weekly hours.

  1. Step 1: Python Basics 3-4 weeks

    Variables, loops, functions, data structures. Python is the #1 language in AI because most ML libraries are written in it.

    Why it matters: Every later step is written in Python — without it nothing else sticks.

    Learn from: CS50P Harvard (free), freeCodeCamp Python (free)

    Topics: Variables & data types, Control flow (if/else, loops), Functions & parameters, Lists, dictionaries, sets, File I/O, Basic error handling

    Must-know: Write clean, readable code; Finish 2 mini projects (e.g. expense tracker)

  2. Step 2: Git, GitHub & Data Handling 2 weeks

    Version control and working with data in Pandas and NumPy.

    Why it matters: Employers look at your GitHub first, and Pandas is how all AI work touches data.

    Learn from: GitHub Skills (free), Kaggle Learn Pandas (free)

    Topics: git add / commit / push, Pull requests, Pandas DataFrames, Cleaning missing values

    Must-know: Public GitHub profile; Clean a real CSV dataset

  3. Step 3: Statistics & Probability Basics 2 weeks

    Mean, median, variance, distributions, sampling. Statistics tells you whether a model's result is real or random noise.

    Why it matters: Without it you cannot tell a good model from a lucky one — interviewers test this.

    Learn from: Khan Academy Statistics (free), StatQuest YouTube (free)

    Topics: Mean, median, mode, Variance & standard deviation, Probability distributions, Sampling & bias, Correlation vs causation

    Must-know: Know when to use mean vs median; Explain correlation vs causation

  4. Step 4: SQL & Data Basics 2 weeks

    Querying data from databases. AI needs data, and most company data lives in SQL databases.

    Why it matters: SQL appears in nearly every junior data/AI interview and job description.

    Learn from: SQLBolt (free), Mode SQL tutorial (free)

    Topics: SELECT, WHERE, GROUP BY, JOINs, Aggregations, Subqueries

    Must-know: Master JOINs and GROUP BY

  5. Step 5: Machine Learning Fundamentals 5-6 weeks

    Supervised learning: regression and classification, train/test split, overfitting, evaluation metrics, using scikit-learn.

    Why it matters: This is the core of every AI role and what separates you from people who only use ChatGPT.

    Learn from: Andrew Ng Machine Learning Specialization (audit free), Google ML Crash Course (free)

    Topics: Supervised vs unsupervised, Linear & logistic regression, Decision trees, Train / test split, Overfitting, Precision, recall, F1

    Must-know: Accuracy alone is not enough; Use scikit-learn pipelines

  6. Step 6: Intro to LLMs & Generative AI 2 weeks

    How large language models work at a high level, prompting, and calling an LLM API from Python.

    Why it matters: Most new AI job posts mention LLMs — even junior candidates are expected to have tried them.

    Learn from: DeepLearning.AI short courses (free), Anthropic / OpenAI API docs (free)

    Topics: Tokens & context windows, Prompting patterns, Calling an API from Python, Basic RAG idea

    Must-know: Ship one tiny LLM app

  7. Step 7: Build 2 Portfolio Projects 4 weeks

    One classic ML project and one LLM project, each with a clear README and a live demo.

    Why it matters: Projects are your proof of skill when you do not have AI work experience.

    Learn from: Kaggle datasets (free), Streamlit / Hugging Face Spaces (free hosting)

    Topics: Problem statement, Data cleaning, Model & evaluation, README with results, Deploy a demo

    Must-know: Live demo link on your resume

    Project ideas
    Loan default predictor: Classic ML on a public lending dataset with a Streamlit demo
    PDF question-answering bot: Small RAG app over your college notes or a public report

  8. Step 8: Apply for Junior Roles ongoing

    Target: Junior ML Engineer, AI Engineer Trainee, ML Intern, Data Analyst (AI track).

    Why it matters: Applying while you keep building compounds — interviews show you what to learn next.

    Learn from: LinkedIn, Naukri, Wellfound, company career pages

    Topics: Resume with project results, LinkedIn posts about what you built, Interview practice

    Must-know: Projects at the top of your resume
